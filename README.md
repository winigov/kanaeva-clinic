# Центр Канаевой — сайт (демо)

Статический сайт центра аллергологии и интегративной медицины доктора Канаевой (Махачкала) в концепции «Свежесть».

**Демо:** https://winigov.github.io/kanaeva-clinic/

Это демонстрационная версия: сайт закрыт от поисковиков (`noindex`, `robots.txt`), сверху есть плашка «Демо-версия», формы записи показывают подтверждение, но заявку никуда не отправляют. Цены, сроки и часть данных помечены на сайте как «уточняется».

## Что внутри

| Путь | Что это |
|---|---|
| `content.py` | Все данные: контакты, реквизиты, врачи, направления, вопросы. Правьте тексты здесь |
| `build.py` | Генератор страниц: собирает HTML в `docs/` из `content.py` |
| `tools/prepare_images.py` | Готовит картинки (WebP двух размеров, логотип, иконки, превью для мессенджеров) из исходников проекта |
| `docs/` | Готовый сайт — его отдаёт GitHub Pages |
| `docs/assets/css/site.css` | Стили |
| `docs/assets/js/site.js` | Меню, окно записи, проверка форм, маска телефона, фильтр врачей |
| `docs/assets/fonts/` | Шрифт Onest (SIL Open Font License, см. `OFL.txt`) |

## Как собрать

Нужен Python 3.10+ и Pillow (`pip install pillow`).

```bash
python3 build.py                  # пересобрать HTML после правок content.py
python3 tools/prepare_images.py   # пересобрать картинки (нужны исходники в ../assets/images)
python3 -m http.server -d docs    # посмотреть локально: http://localhost:8000
```

После сборки закоммитьте изменения в `docs/` — GitHub Pages опубликует их сам.

## Переход с демо на рабочий сайт

1. В `content.py` поставить `DEMO = False` и указать настоящий адрес в `SITE_URL` — пропадёт плашка и запрет индексации.
2. Заменить все значения «уточняется»: цены, длительность приёма, парковка, контакты контролирующих органов.
3. Подключить отправку заявок (Telegram-бот, почта или CRM) в `docs/assets/js/site.js`.
4. Разместить текст политики обработки персональных данных и согласия.
5. Проверить перечень работ по лицензии и согласовать с клиникой список направлений.
6. Показать врачам обработанные портреты и получить их согласие.
